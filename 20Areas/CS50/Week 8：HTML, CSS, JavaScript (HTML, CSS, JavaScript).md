## 网络基础 (Internet Fundamentals)

*   **TCP/IP：** 用于传输数据包的协议。IP 地址标识计算机。
*   **DNS (Domain Name System)：** 将域名（如 harvard.edu）转换为 IP 地址。

## HTTP 协议 (HTTP Protocol)

*   使用 `GET`（请求数据）和 `POST`（发送数据）请求。
*   **状态码：** `200 OK`, `301/302 Redirect`, `404 Not Found`, `500 Internal Error`。

## HTML (Hypertext Markup Language)

*   网页的结构框架，使用标签（`<html>`, `<head>`, `<body>`）。
*   **常用元素：** `<p>` (段落), `<h1>-<h6>` (标题), `<ul>/<ol>` (列表), `<table>`, `<img>`, `<a>` (链接)。
*   **表单 (Forms)：** 用于通过 `<input>` 和 `<button>` 收集用户输入。

## CSS (Cascading Style Sheets)

*   用于美化和布局。
*   **选择器：** 标签选择器、`.类选择器`和`#ID选择器`。
*   **框架 (Bootstrap)：** 提供预制 CSS 类，使网站快速变得专业且具有响应式 (Responsive)。

## JavaScript (Interactivity)

*   用于客户端交互的编程语言。
*   **DOM (Document Object Model)：** 允许 JavaScript 动态读取和修改 HTML 内容。
*   **功能示例：** `alert`, `addEventListener`, `setInterval`, `fetch` (调用 API)。
