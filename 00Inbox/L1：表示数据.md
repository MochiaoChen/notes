## 欢迎！

## IDE

IDE 是集成开发环境 (Integrated Development Environment, IDE)，这是一套预先配置好的、可用于编程的工具。

R 拥有自己的 IDE，称为 RStudio，它专门用于 R 语言编程。

在 RStudio 中，请注意 `>` 符号。这表示 R 控制台 (Console)，我们可以在这里发布命令。

## 创建你的第一个程序

你可以在 R 控制台输入 `file.create("hello.R")` 并按下键盘上的回车或返回键来创建你的第一个程序。

请注意 `hello.R` 以 `.R` 结尾。你过去可能见过其他带有 `.jpg` 或 `.gif` 后缀的文件。`.R` 是 R 语言使用的特定文件扩展名 (File Extension)。

当你发布上述命令时，你应该在 R 控制台中看到 `[1] TRUE`。稍后会详细介绍！

在 R 控制台的右侧，你可以访问文件浏览器。观察 `hello.R` 是如何在我们的工作目录 (Working Directory) 中创建的：这是默认情况下保存我们所有文件的地方。

我们可以通过双击来打开 `hello.R` 文件。

此时会出现文件编辑器 (File Editor)，这是一个我们可以编写多行代码的地方。
在文件编辑器中，按照以下内容输入你的第一个程序：
```r
print("hello, world")
```
注意这里出现的所有文本和字符。它们都是必需的。

你可以通过点击保存图标进行保存。

你可能习惯于通过双击图标来运行程序。但在 R 内部，我们必须采取不同的方法来运行程序。

R 不仅仅是一种编程语言。它同时也是一个解释器 (Interpreter)，能够将我们的源代码 (Source Code) 转换为计算机可以理解并运行的内容。

我们可以通过点击运行 (Run) 按钮来执行此过程。观察 “hello, world” 现在是如何显示的。做得好！

该函数的副作用 (Side Effect) 是在 R 控制台中显示 “hello, world”。

## readline

在 R 中，`readline` 函数可以读取来自用户的输入。

如下修改你的代码：

```r
readline("What's your name? ")
print("Hello, Carter")
```

请注意，如果我们运行这段代码，“Carter” 将始终出现。

我们需要创建一种方法，通过这种方法我们可以读取并使用用户给出的姓名。

函数不仅拥有参数和副作用。它们还拥有返回值 (Return Values)。返回值由函数提供回来。我们可以将返回的值存储为变量 (Variables)。在 R 中，变量也可以被称为对象 (Objects)，以避免与统计变量：一个不同的概念：相混淆！

如下修改你的代码：

```r
name <- readline("What's your name? ")
print("Hello, name")
```

观察名为 `name` 的变量如何存储 `readline` 的返回值。箭头 `<-` 表示返回值正在从 `readline` 传递到 `name`。这个箭头被称为赋值操作符 (Assignment Operator)。

运行这段代码并打开 IDE 右侧的环境 (Environment) 窗口，你可以看到程序中的变量以及其中存储的内容。

## paste

尽管如此，运行这段代码时，请注意 “name” 始终会出现。这显然是一个程序错误！

我们可以按照以下方式修正这个错误：

```r
name <- readline("What's your name? ")
greeting <- paste("Hello, ", name)
print(greeting)
```

注意第一行代码保持不变。观察我们如何创建一个名为 `greeting` 的新变量，并将 “Hello, ” 与 `name` 的字符串拼接 (String Concatenation) 结果赋值给 `greeting`。字符串 (Strings) 是字符的集合。两个独立的字符串使用 `paste` 函数组合成一个。生成的变量 `greeting` 使用 `print` 函数打印。

运行这段代码，注意环境中出现的新变量。

如果你观察得格外仔细，会发现这里仍然有一个程序错误！`greeting` 中存储了两个空格，分别位于 “Hello,” 和 `name` 的值之间。
## 文档

可以通过在 R 控制台中输入 `?paste` 来访问 `paste` 的文档 (Documentation)。相应地，`paste` 的文档将会出现。阅读这份文档，人们可以了解可以与 `paste` 一起使用的各种形参 (Parameters)。

一个与我们当前工作相关的参数是 `sep`。

如下修改你的代码：

```r
name <- readline("What's your name? ")
greeting <- paste("Hello, ", name, sep = "")
print(greeting)
```

观察 `sep = ""` 是如何添加到代码中的。

运行此程序，你会看到输出现在按预期工作。

恰好程序员们经常需要通过将 `sep` 设置为 `""` 来省略这些额外的空格。因此，他们发明了 `paste0`，它可以在没有任何分隔字符的情况下拼接字符串。`paste0` 可以按照以下方式使用：

```r
name <- readline("What's your name? ")
greeting <- paste0("Hello, ", name)
print(greeting)
```

观察 `paste` 是如何变成 `paste0` 的。

你的程序可以进一步简化如下：

```r
# 询问用户的姓名
name <- readline("What's your name? ")

# 向用户问好
print(paste("Hello,", name))
```

注意这里通过将 `paste` 的返回值直接作为 `print` 的输入值传递，从而消除了 `greeting` 变量。

最后，当像上面那样在函数中嵌套函数时，请考虑你和其他人在阅读代码时可能面临的进一步挑战。有时，过多的嵌套会导致无法理解代码在做什么。这是一个设计决策。也就是说，你经常会为了造福用户和程序员而对代码做出决策。

此外，你可能会做出的一个风格决策是使用 `#` 符号包含注释 (Comments)，在其中描述一段代码正在做什么。

## 算术

让我们创建一个新程序，为一些虚构角色计算选票。

关闭 `hello.R` 文件。

在你的控制台中，输入 `file.create("count.R")`。

如下创建你的代码：

```r
mario <- readline("Enter votes for Mario: ")
peach <- readline("Enter votes for Peach: ")
bowser <- readline("Enter votes for Bowser: ")

total <- mario + peach + bowser

print(paste("Total votes:", total))
```

注意 `readline` 的返回值是如何存储在名为 `mario`、`peach` 和 `bowser` 的三个变量中的。变量 `total` 被赋予了 `mario`、`peach` 和 `bowser` 相加后的值。然后，打印出总数。

R 拥有许多算术操作符 (Arithmetic Operators)，包括 `+`、`-`、`*`、`/` 等等！

运行这段代码并输入票数，会产生一个错误。

事实证明，来自用户的输入被视作字符串而非数字。查看环境，注意 `mario` 和其他变量的值在存储时带有引号。这些引号表明它们是作为字符型字符串 (Character Strings) 而非数字存储的。这些值必须是数字才能使用 `+` 进行相加。

在 R 中，变量可以以不同的模式 (Modes)，有时也称为「类型」(Types)：进行存储。其中一些「存储模式」(Storage Modes) 包括字符型 (character)、双精度浮点型 (double) 和整型 (integer)。

我们可以按照以下方式将这些变量转换为我们想要的存储模式：

```r
mario <- readline("Enter votes for Mario: ")
peach <- readline("Enter votes for Peach: ")
bowser <- readline("Enter votes for Bowser: ")

mario <- as.integer(mario)
peach <- as.integer(peach)
bowser <- as.integer(bowser)

total <- mario + peach + bowser

print(paste("Total votes:", total))
```

观察这里如何通过 `as.integer` 采用强制类型转换 (Coercion) 来将 `mario` 等变量转换为整数。

运行这段代码并查看环境，你可以看到这些值现在正作为不带引号的整数进行存储。

该程序可以进一步简化如下：

```r
mario <- as.integer(readline("Enter votes for Mario: "))
peach <- as.integer(readline("Enter votes for Peach: "))
bowser <- as.integer(readline("Enter votes for Bowser: "))

total <- sum(mario, peach, bowser)

print(paste("Total votes:", total))
```

观察这里如何使用 `sum` 函数来对三个变量的值求和。

有没有一种方法可以让我们利用预先存在的数据源呢？

## 表格

表格 (Tables) 是我们可以用来组织数据的众多结构之一。

表格是一组行和列，其中行通常代表被存储的某个实体，而列代表这些实体各自的属性。

表格可以以多种文件格式存储。一种常见的格式是逗号分隔值 (Comma-Separated Values, CSV) 文件。

在 CSV 文件中，每一行存储在单独的一行中。各列由逗号分隔。

在我们开始下一个程序之前，在 R 控制台中输入 `ls()` 以确定环境中所有活动的变量。然后，输入 `rm(list = ls())` 以从你的环境中删除所有这些值。再次输入 `ls()`，你会注意到环境中没有剩下的对象了。

接下来，输入 `file.create("tabulate.R")` 来创建我们的新程序文件。打开你的文件浏览器，打开 `tabulate.R` 文件。此外，你应该从创建 `votes.csv` 文件并将其拖入你的工作目录。

 `votes.csv` 的内容如下

```csv
candidate,poll,mail
Mario,37,63
Peach,43,107
Bowser,84,36
```

如下创建你的代码：
```r
votes <- read.table("votes.csv")
View(votes)
```

`View(votes)` 注意第一行代码如何将 `votes.csv` 中的表格读入 `votes` 变量。然后，`View` 允许你查看 `votes` 中存储的内容。

运行这段代码，你现在可以在一个单独的标签页中看到 `votes` 对象中存储的内容。然而，存在一个错误。注意所有数据都被读入了一列。看起来 `read.table` 正在从 CSV 文件读取数据。但是，似乎还需要进行一些格式化。

如下修改你的代码：

```r
votes <- read.table(
"votes.csv",
sep = ","
)
View(votes)
```

`View(votes)` 观察 `sep` 是如何被用来告诉 `read.table` 每一列将在哪个字符上进行分隔。

运行这段代码，仍然存在一个错误。我们如何让 `read.table` 识别表格的表头 (Header) 呢？

如下修改你的代码：

```r
votes <- read.table(
"votes.csv",
sep = ",",
header = TRUE
)
View(votes)
```
观察 `header = TRUE` 参数如何允许 `read.table` 识别存在表头。

运行此文件，表格将按预期显示。

程序员们已经创建了一个快捷方式来更简单地完成这项工作。如下修改你的代码：

```r
votes <- read.csv("votes.csv")
View(votes)
```

观察 `read.csv` 如何以比之前的代码大得多的简洁性完成任务！

既然我们的数据已经加载，我们该如何访问它？如下修改你的代码：

```r
votes <- read.csv("votes.csv")

votes[, 1]
votes[, 2]
votes[, 3]
```

观察括号表示法 (Bracket Notation) 是如何被用来以 `votes[行, 列]` 的格式访问值的。因此，`votes[, 2]` 将显示 `poll`（民意调查）列中的数字。

## 向量

向量 (Vectors) 是具有相同存储模式的一组值的列表。

考虑到我们关于候选人和选票的数据框 (Data Frame)，或者叫表格，我们可以通过创建一个新向量来访问特定的值。

我们可以通过调用每一列的精确名称来简化这个程序：

```r
votes <- read.csv("votes.csv")

colnames(votes)

votes$candidate
votes$poll
votes$mail
```

观察 `votes$poll` 如何返回一个包含 `poll` 列中所有值的向量。我们现在可以使用这个新向量访问 `poll` 列的值。

运行这段代码，注意每一列的值是如何出现的。

回到关于如何对这些值求和的原始问题，如下修改你的代码：

```r
votes <- read.csv("votes.csv")

sum(votes$poll[1], votes$poll[2], votes$poll[3])
```

观察这里如何使用 `sum` 对 `poll` 列的第一行、第二行和第三行的值求和。

然而，这段代码不是动态的。它相当僵化。如果有三位以上的候选人怎么办？因此，我们可以如下简化我们的代码，使其更具动态性：

```r
votes <- read.csv("votes.csv")

sum(votes$poll)
sum(votes$mail)
```

注意这里如何对向量 `votes$poll` 和 `votes$mail` 中发现的值求和。

正如上面使用括号表示法所演示的那样，我们也可以尝试对每一行中 `poll` 和 `mail`列的值进行求和。如下修改你的代码：

```r
votes <- read.csv("votes.csv")

votes$poll[1] + votes$mail[1]
votes$poll[2] + votes$mail[2]
votes$poll[3] + votes$mail[3]
```

观察 `poll` 和 `mail` 的每一行是如何相加的。

不过，这是 R 提供的最佳方法吗？

## 向量算术

很多时候，我们希望能够将一个向量的行与另一个向量的行相加。我们可以通过向量算术 (Vector Arithmetic) 来做到这一点。

本着让我们的代码更具动态性的精神，我们可以进一步如下修改我们的代码：

```r
votes <- read.csv("votes.csv")

votes$poll + votes$mail
```

观察向量是如何进行逐元素 (Element-wise) 相加的。也就是说，第一个向量的第一行与第二个向量的第一行相加，第一个向量的第二行与第二个向量的第二行相加，依此类推。这会产生一个最终向量，其行数与 `poll` 和 `mail` 向量相同。

向量算术会产生一个全新的向量。我们可以以多种方式处理这个新向量。

自然地，我们可能想要存储算术运算的结果。我们可以通过如下修改代码来做到这一点：

```r
votes <- read.csv("votes.csv")

votes$total <- votes$poll + votes$mail

write.csv(votes, "totals.csv")
```

注意最终的总数是如何存储在一个名为 `votes$total` 的新向量中的，实际上它是 `votes` 数据框的一个新总计列。然后我们将生成的 `votes` 数据框写入一个名为 `totals.csv` 的文件。

当你查看 CSV 文件时，会出现一个问题。注意在默认情况下，「行名」(row names) 会被包含在内。可以通过如下修改代码来排除这些内容：

```r
votes <- read.csv("votes.csv")

votes$total <- votes$poll + votes$mail

write.csv(votes, "totals.csv", row.names = FALSE)
```

注意 `row.names` 是如何被设置为 `FALSE` 的。

```r
url <- "https://github.com/fivethirtyeight/data/raw/master/non-voters/nonvoters_data.csv"
```

```r
unique(voters$voter_category)
```


注意这里如何使用 `unique` 来确定参与者可能选择的选项。

R 中的其他特殊值包括 `Inf`、`-Inf`、`NaN` 和 `NULL`。它们分别代表无穷大、负无穷大、非数字 (Not a Number) 以及空值（或无值）。

```r
# Demonstrates NA
```

## 因子

`Q21` 涉及参与者在未来选举中投票的计划。在该列中，数值 `1`、`2` 和 `3` 对应于特定的可能答案。例如，`1` 可能代表 “Yes”。

在 R 中，我们可以使用 `factor`（因子）将数字值转换为特定的基于文本的答案。例如，我们可以使用 `factor` 将数字 `1` 更改为对应文本 “Yes”。我们可以通过如下修改代码来完成此操作：

```r
# 演示将向量转换为因子
url <- "https://github.com/fivethirtyeight/data/raw/master/non-voters/nonvoters_data.csv"

voters <- read.csv(url)
voters$Q21
factor(
  voters$Q21
)
factor(
  voters$Q21,
  labels = c("?", "Yes", "No", "Unsure/Undecided")
)
```

注意 `factor(voters$Q21)` 将显示 `Q21` 数据的特定水平 (Levels)：即类别。在代码稍后出现的因子中，标签 (Labels) 被应用于每个水平。例如，`1` 与 “Yes” 相关联。

在许多情况下，我们可能想要排除某些值。在 `Q21` 中，我们可能希望排除 `-1`，因为不清楚这个值代表什么。我们可以如下操作：


```r
# 演示从因子的水平中排除值
url <- "https://github.com/fivethirtyeight/data/raw/master/non-voters/nonvoters_data.csv"

voters <- read.csv(url)
voters$Q21 <- factor(
  voters$Q21,
  labels = c("Yes", "No", "Unsure/Undecided"),
  exclude = c(-1)
)
```

观察 `-1` 是如何被排除的。
