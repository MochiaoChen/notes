

## 【作业 1.1 OLG 模型 : 无约束问题】

假设消费者生存两期：在第一期通过劳动获得收入，获得的收入除了用来满足该期的消费外，其余用来储蓄；在第二期（退休后）不劳动，没有劳动收入，靠第一期的储蓄来满足他在该期的消费 。假设第 t 代的人在第 t 期出生，他在第 t 期是年轻人，在第 t+1 期是老年人 。因此，每期拥有两代人，在 t 期出生的年轻人和 t-1 期的老年人 。

记第 t 期出生的人在第 t 期的消费为 $c_{1,t}$，在第 t+1 期的消费为 $c_{2,t+1}$，在 t 期的储蓄为 $s_{t}$，劳动收入为 $w_{t}$，完全竞争市场下的利率为 $r$ 。消费者一生的效用水平可以写成 $U(c_{1,t},c_{2,t+1})=U(c_{1,t})+\beta U(c_{2,t+1})$ ，消费者在 t, t+1 期的预算约束可以写成：

$$c_{1,t}+s_{t}=w_{t}$$

$$c_{2,t+1}=(1+r_{t+1})s_{t}$$

### 1) 请写出消费者的最优化问题，并利用非线性优化求解方法求解 。 

在世代交叠模型（Overlapping Generations，简称 OLG）中，代表性消费者在其生命周期内需要决定当期的消费 $c_{1,t}$ 与储蓄 $s_{t}$，以及下一期（老年期）的消费 $c_{2,t+1}$。

根据题意，我们可以将第一期和第二期的预算约束合并，消去储蓄变量 $s_{t}$，得到消费者一生的生命周期预算约束（Lifetime Budget Constraint）：

$$c_{1,t} + \frac{c_{2,t+1}}{1+r_{t+1}} = w_{t}$$

消费者的最优化问题可以写为：

$$\max_{c_{1,t}, c_{2,t+1}} U(c_{1,t}) + \beta U(c_{2,t+1})$$

受到如下约束：

$$c_{1,t} + \frac{c_{2,t+1}}{1+r_{t+1}} = w_{t}$$

采用非线性优化中的拉格朗日乘数法（Lagrange Multiplier Method），构造拉格朗日函数 $\mathcal{L}$：

$$\mathcal{L} = U(c_{1,t}) + \beta U(c_{2,t+1}) + \lambda \left[ w_{t} - c_{1,t} - \frac{c_{2,t+1}}{1+r_{t+1}} \right]$$

分别对 $c_{1,t}$ 和 $c_{2,t+1}$ 求偏导并令其等于 0，得到一阶最优化条件（First-Order Conditions，简称 FOC）：

$$\frac{\partial \mathcal{L}}{\partial c_{1,t}} = U'(c_{1,t}) - \lambda = 0 \implies U'(c_{1,t}) = \lambda$$

$$\frac{\partial \mathcal{L}}{\partial c_{2,t+1}} = \beta U'(c_{2,t+1}) - \frac{\lambda}{1+r_{t+1}} = 0 \implies \lambda = \beta (1+r_{t+1}) U'(c_{2,t+1})$$

联立上述两式消去拉格朗日乘数 $\lambda$，得到描述消费者跨期最优消费路径的欧拉方程（Euler Equation）：

$$U'(c_{1,t}) = \beta (1+r_{t+1}) U'(c_{2,t+1})$$
### 2) 假设 CES 形式的效用函数 $U(c)=\frac{c^{1-\theta}-1}{1-\theta}(0<\theta<1)$，请根据最优化条件写出储蓄函数表达式，并讨论工资率、利率变化对于储蓄行为的影响 $\frac{\partial s_{t}}{\partial w_{t}}$, $\frac{\partial s_{t}}{\partial r_{t+1}}$ 。 

给定常数替代弹性（Constant Elasticity of Substitution，简称 CES）效用函数 $U(c) = \frac{c^{1-\theta}-1}{1-\theta}$，且参数满足 $0 < \theta < 1$。其边际效用为 $U'(c) = c^{-\theta}$。

将边际效用代入上文求得的欧拉方程中：

$$c_{1,t}^{-\theta} = \beta (1+r_{t+1}) c_{2,t+1}^{-\theta}$$

将第一期预算约束 $c_{1,t} = w_{t} - s_{t}$ 和第二期预算约束 $c_{2,t+1} = (1+r_{t+1})s_{t}$ 代入上式：

$$(w_{t} - s_{t})^{-\theta} = \beta (1+r_{t+1}) [(1+r_{t+1})s_{t}]^{-\theta}$$

对方程两边同时取 $-1/\theta$ 次方：

$$w_{t} - s_{t} = [\beta (1+r_{t+1})^{1-\theta}]^{-1/\theta} s_{t}$$

将含有 $s_{t}$ 的项移至等号同一侧并提取公因式：

$$w_{t} = s_{t} \left[ 1 + \beta^{-1/\theta} (1+r_{t+1})^{(\theta-1)/\theta} \right]$$

整理得到最优储蓄函数表达式：

$$s_{t} = \frac{1}{1 + \beta^{-1/\theta} (1+r_{t+1})^{(\theta-1)/\theta}} w_{t}$$

**比较静态分析：**

1. **工资率变化对于储蓄行为的影响：**
    
    $$\frac{\partial s_{t}}{\partial w_{t}} = \frac{1}{1 + \beta^{-1/\theta} (1+r_{t+1})^{(\theta-1)/\theta}} > 0$$
    
    这表明在其他条件不变的情况下，当期工资率的增加会促使消费者增加储蓄。这是消费平滑（Consumption Smoothing）动机的体现，消费者会将增加的收入分配到生命周期的两个阶段。
    
2. **利率变化对于储蓄行为的影响：**
    
    利用链式法则对 $r_{t+1}$ 求偏导：
    
    $$\frac{\partial s_{t}}{\partial r_{t+1}} = -w_{t} \left[ 1 + \beta^{-1/\theta} (1+r_{t+1})^{(\theta-1)/\theta} \right]^{-2} \cdot \beta^{-1/\theta} \frac{\theta-1}{\theta} (1+r_{t+1})^{-1/\theta}$$
    
    由于题目设定 $0 < \theta < 1$，可得 $\frac{\theta-1}{\theta} < 0$。同时其他项均为正数，前方的负号与该项相乘后结果为正。因此：
    
    $$\frac{\partial s_{t}}{\partial r_{t+1}} > 0$$
    
    这表明当 $0 < \theta < 1$ 时，利率的上升会导致消费者增加储蓄。在经济学直觉上，利率上升同时带来了替代效应（推迟消费变得更具吸引力）和收入效应（达到既定老年消费水平所需的当期储蓄减少）。在此参数范围内，替代效应主导了收入效应。
### 3) 假设平方根形式的效用函数 $U(c)=\sqrt{c}$

题目中提及利用线性优化求解方法，考虑到平方根效用函数 $U(c) = \sqrt{c}$ 为严格凹函数，且预算约束为线性，该问题是一个标准的凸优化问题。一阶条件（FOC）即为全局最优的充分必要条件。此时相当于 CES 效用函数中 $\theta = 0.5$ 的情况，边际效用为 $U'(c) = 0.5 c^{-0.5}$。

将其代入欧拉方程中：

$$0.5 c_{1,t}^{-0.5} = \beta (1+r^{f}) 0.5 c_{2,t+1}^{-0.5}$$

两边平方并整理得到最优的跨期消费路径：

$$c_{2,t+1} = [\beta(1+r^{f})]^2 c_{1,t}$$
### **养老金体系的引入和比较：基金制和现收现付制度 Pay As You Go**

A. 基金式的养老金制度 政府以一定比例向收入为 $w$ 的工人收税 $\tau w$（养老金相当于强制储蓄计划，类似于税收） 。政府代表工人将他们的收入进行投资，得到实际利率为 $r^{f}$ 的回报率，当他们退休时，这些收益会返还给年老时候的社保参与人 。假设私人储蓄在债券市场获得的收益为常数 $r^{xs}$ ，因此消费者在 t, t+1 期的预算约束可以写成：

$$c_{1,t}+s_{t}=w_{t}-\tau w_{t}$$

$$c_{2,t+1}=(1+r^{f})s_{t}+(1+r^{xs})\tau w_{t}$$

B. 现收现付制度 Pay As You Go 的养老金制度 原理是当代的年轻人通过向政府缴税的形式赡养当代的老年人 。首先假设人口结构：每个时期新增 $N_{t}$ 个工人出生，年轻工人的人口数按 $N_{t+1}=(1+n)N_{t}$ 增长 。如果政府向每个年轻工人收一定数量的税作为养老金的来源，那么政府的总收入为 $G=N_{t}\tau w_{t}$ 。把这些养老金平均地分配给当期的老人，每个老人将得到 $\frac{G}{N_{t-1}}$ ，也就是：

$$\frac{G}{N_{t-1}}\equiv g=\frac{N_{t}\tau w_{t}}{N_{t-1}}=(1+n)\tau w_{t}$$

因此消费者在 t, t+1 期的预算约束可以写成：

$$c_{1,t}+s_{t}=w_{t}-\tau w_{t}$$

$$c_{2,t+1}=(1+r^{f})s_{t}+g=(1+r^{f})s_{t}+(1+n)\tau w_{t}$$
>$Hint$：这里的关键是，当人口增长足够快时，现收现付制的养老金制度优于讨论的基金制 。
#### a) 请利用线性优化求解方法，分别求出基金制和现收现付制度下消费者最优的储蓄选择$s^{*}_t$、对应的两期消费的水平 $c^{*}_{1,t}$ ,$c^{*}_{2,t+1}$ 的显示解 。

**A. 基金制的养老金制度（Funded Pension System）**

将两期预算约束合并为生命周期总约束：

$$c_{1,t} + \frac{c_{2,t+1}}{1+r^{f}} = w_{t}(1-\tau) + \frac{(1+r^{xs})\tau w_{t}}{1+r^{f}}$$

代入上述跨期消费路径关系，解得最优当期消费：

$$c_{1,t}^{*}|_{fund} = \frac{1}{1+\beta^2(1+r^{f})} \left[ w_{t}(1-\tau) + \frac{1+r^{xs}}{1+r^{f}} \tau w_{t} \right]$$

进一步得到最优老年消费：

$$c_{2,t+1}^{*}|_{fund} = \frac{[\beta(1+r^{f})]^2}{1+\beta^2(1+r^{f})} \left[ w_{t}(1-\tau) + \frac{1+r^{xs}}{1+r^{f}} \tau w_{t} \right]$$

最优个人储蓄等于当期可支配净收入减去当期消费：

$$s_{t}^{*}|_{fund} = w_{t}(1-\tau) - c_{1,t}^{*}|_{fund} = \frac{\beta^2(1+r^{f}) w_{t}(1-\tau) - \frac{1+r^{xs}}{1+r^{f}} \tau w_{t}}{1+\beta^2(1+r^{f})}$$

**B. 现收现付制度（Pay As You Go, PAYG）**

合并该制度下的预算约束：

$$c_{1,t} + \frac{c_{2,t+1}}{1+r^{f}} = w_{t}(1-\tau) + \frac{(1+n)\tau w_{t}}{1+r^{f}}$$

同理代入跨期消费路径，解得最优当期消费：

$$c_{1,t}^{*}|_{PAYG} = \frac{1}{1+\beta^2(1+r^{f})} \left[ w_{t}(1-\tau) + \frac{1+n}{1+r^{f}} \tau w_{t} \right]$$

最优老年消费：

$$c_{2,t+1}^{*}|_{PAYG} = \frac{[\beta(1+r^{f})]^2}{1+\beta^2(1+r^{f})} \left[ w_{t}(1-\tau) + \frac{1+n}{1+r^{f}} \tau w_{t} \right]$$

最优个人储蓄为：

$$s_{t}^{*}|_{PAYG} = w_{t}(1-\tau) - c_{1,t}^{*}|_{PAYG} = \frac{\beta^2(1+r^{f}) w_{t}(1-\tau) - \frac{1+n}{1+r^{f}} \tau w_{t}}{1+\beta^2(1+r^{f})}$$
#### b) 根据 a)，试比较两种养老制度下最优的个人储蓄水平 $s_{t}^{*}|_{fund}$ 和 $s_{t}^{*}|_{PAYG}$（个人养老承担部分）的大小 。

我们可以直接计算两种制度下私人储蓄水平的差值：

$$s_{t}^{*}|_{fund} - s_{t}^{*}|_{PAYG} = c_{1,t}^{*}|_{PAYG} - c_{1,t}^{*}|_{fund}$$

$$= \frac{\tau w_{t}}{[1+\beta^2(1+r^{f})](1+r^{f})} (n - r^{xs})$$

**比较结果及经济学直觉：**

由于公式右侧的系数恒为正数，两种储蓄水平的大小完全取决于人口增长率 $n$ 与债券市场收益率 $r^{xs}$ 的相对大小。

1. **当 $n > r^{xs}$ 时，$s_{t}^{*}|_{PAYG} < s_{t}^{*}|_{fund}$。**
    
    当人口增长足够快，使得现收现付制带来的隐含收益率（人口红利）高于基金制下债券市场的投资回报率时，现收现付制（PAYG）为消费者带来了绝对更高的终身财富预期。由于任何一期的消费均可视为正常商品，财富的增加必定带来第一期最优消费水平 $c_{1,t}$ 的上升。在面临相同的一期税后工资 $w_{t}(1-\tau)$ 时，消费的增加必然挤出当期的个人储蓄。在此情形下，现收现付制在帕累托意义上优于基金制。
    
2. **当 $n < r^{xs}$ 时，$s_{t}^{*}|_{PAYG} > s_{t}^{*}|_{fund}$。**
    
    若人口增长放缓，甚至低于资本市场的回报率，基金制能带来更高的终身总收入。此时，消费者在现收现付制度下会预见未来养老金相对不足，从而进行预防性动机的替代储蓄，导致 PAYG 下的私人储蓄高于基金制。

## 【作业 1.2 CIA 模型 : 不等式约束问题】

考虑货币先行模型 (CIA)，消费者需要决定消费量 $c_{t}$，劳动供给量 $l_{t}$，储蓄量 $s_{t+1}$，和货币持有量 $m_{t+1}$ 。效用函数的形式如下：

$$\max_{c_{t},l_{t},s_{t+1},m_{t+1}}\sum_{t=0}^{\infty}\beta^{t}[\ln(c_{t})+\ln(1-l_{t})]$$

其中，$\beta$ 是从零期到第一期的贴现因子 。经济中只有一种商品，消费者可以通过 $y=A+l$ 的技术来生产这种商品（假设 $A$ 为不变的技术水平） 。消费者在 t 时期的预算约束如下：

$$m_{t+1}+s_{t+1}+P_{t}c_{t}=m_{t}+(1+R_{t})s_{t}+P_{t}y_{t}+\tau_{t}$$

其中，$R_{t}$ 表示储蓄获得的名义利率，$P_{t}$ 表示 t 时期的商品价格，$\tau_{t}$ 表示政府的转移支付 。中央银行将货币直接发给消费者 。货币政策包括货币的印刷和将其作为一种转移支付给予消费者 。当中央银行想要减少货币供给时，会通过使 $\tau_{t}$ 为负来向每个消费者征税 。货币供给记为 $M$ 。为了简便，我们以每个消费者的货币持有 $m$ 来表达货币政策 。此外，我们假设一个非常简单的货币政策：中央银行以固定的增长率 $g$ 来增加货币供给 。

$$m_{t+1}=m_{t}+\tau_{t}=(1+g)m_{t}$$

### 1) 请从消费者最优化的角度（而不是可行性的角度）写出货币先行 (CIA) 预算约束，并解释其含义（10 分） 。 

在货币先行模型（Cash-in-Advance Model，简称 CIA 模型）中，消费者面临的交易摩擦通过一个流动性约束来体现。假设消费者在当期商品市场开启前收到政府的转移支付 $\tau_{t}$，那么从消费者最优化的角度来看，其货币先行约束可以写为：

$$P_{t}c_{t} \le m_{t} + \tau_{t}$$

**含义解释：**
这一约束表明，消费者在 $t$ 时期购买消费品 $c_{t}$ 的名义总支出 $P_{t}c_{t}$，必须小于或等于他们在进入商品市场前所持有的货币余额。该余额由上一期结转的货币 $m_{t}$ 以及当期来自政府的转移支付 $\tau_{t}$ 组成。

由于商品市场和要素 / 资产市场存在时间或空间上的分离，消费者当期通过劳动获得的收入 $P_{t}y_{t}$ 以及储蓄带来的本息收入 $(1+R_{t})s_{t}$ 无法立即用于当期的商品消费，只能带入下一期。这种机制人为地制造了持有货币的需求，也设定了通货膨胀对消费和劳动决策产生扭曲的微观基础。

### 2) 请写出代表性家庭的最优化问题，并求解消费量 $c_{t}$，劳动供给量 $l_{t}$，储蓄量 $s_{t+1}$，和货币持有量 $m_{t+1}$ 相关最优条件（10 分） 。 

代表性家庭的目标是在面临预算约束和货币先行约束的情况下，最大化其一生的贴现效用。该最优化问题可以写为：

$$\max_{c_{t},l_{t},s_{t+1},m_{t+1}} \sum_{t=0}^{\infty} \beta^{t} [\ln(c_{t}) + \ln(1-l_{t})]$$

约束条件为：
1. 预算约束：$P_{t}c_{t} + m_{t+1} + s_{t+1} = m_{t} + \tau_{t} + (1+R_{t})s_{t} + P_{t}(A + l_{t})$
2. 货币先行约束：$P_{t}c_{t} \le m_{t} + \tau_{t}$

我们构造拉格朗日 (Lagrangian) 函数。设 $\lambda_{t}$ 为 $t$ 期预算约束的拉格朗日乘子，$\mu_{t}$ 为 $t$ 期货币先行约束的拉格朗日乘子，并假设消费者将转移支付 $\tau_{t}$ 和价格 $P_{t}$ 视为外生给定：

$$\mathcal{L} = \sum_{t=0}^{\infty} \beta^{t} \left\{ \ln(c_{t}) + \ln(1-l_{t}) + \lambda_{t} [m_{t} + \tau_{t} + (1+R_{t})s_{t} + P_{t}(A + l_{t}) - P_{t}c_{t} - m_{t+1} - s_{t+1}] + \mu_{t} [m_{t} + \tau_{t} - P_{t}c_{t}] \right\}$$

分别对 $c_{t}$、$l_{t}$、$s_{t+1}$ 和 $m_{t+1}$ 求一阶导数（FOCs）：

1. **对消费 $c_{t}$ 的一阶条件：**
   $$\frac{\partial \mathcal{L}}{\partial c_{t}} = \beta^{t} \left[ \frac{1}{c_{t}} - \lambda_{t}P_{t} - \mu_{t}P_{t} \right] = 0 \implies \frac{1}{c_{t}} = P_{t}(\lambda_{t} + \mu_{t})$$

2. **对劳动供给 $l_{t}$ 的一阶条件：**
   $$\frac{\partial \mathcal{L}}{\partial l_{t}} = \beta^{t} \left[ -\frac{1}{1-l_{t}} + \lambda_{t}P_{t} \right] = 0 \implies \frac{1}{1-l_{t}} = \lambda_{t}P_{t}$$

3. **对储蓄 $s_{t+1}$ 的一阶条件：**
   对 $s_{t+1}$ 求导涉及当期的 $-s_{t+1}$ 以及下一期的 $(1+R_{t+1})s_{t+1}$：
   $$\frac{\partial \mathcal{L}}{\partial s_{t+1}} = -\beta^{t}\lambda_{t} + \beta^{t+1}\lambda_{t+1}(1+R_{t+1}) = 0 \implies \lambda_{t} = \beta \lambda_{t+1}(1+R_{t+1})$$

4. **对货币持有量 $m_{t+1}$ 的一阶条件：**
   对 $m_{t+1}$ 求导涉及当期的 $-m_{t+1}$ 以及下一期预算约束和 CIA 约束中的 $m_{t+1}$：
   $$\frac{\partial \mathcal{L}}{\partial m_{t+1}} = -\beta^{t}\lambda_{t} + \beta^{t+1}\lambda_{t+1} + \beta^{t+1}\mu_{t+1} = 0 \implies \lambda_{t} = \beta (\lambda_{t+1} + \mu_{t+1})$$

同时需满足互补松弛条件：$\mu_{t} \ge 0$ 且 $\mu_{t}(m_{t} + \tau_{t} - P_{t}c_{t}) = 0$。
### 3) 请求解出稳态时的竞争性均衡（此时模型中任意实际变量 $x_{t+n}=x_{t}$）时最优的消费量 $c_{t}$，劳动供给量 $l_{t}$，储蓄量 $s_{t+1}$（10 分） 。 


在稳态下，所有的实际变量保持不变。具体而言，实际消费 $c_{t} = c$，实际劳动供给 $l_{t} = l$。由于这是一个没有物质资本且代理人同质的封闭经济体，债券市场的净供给为零，因此代表性家庭的储蓄量始终为零，即 $s_{t+1} = 0$。

根据货币政策 $m_{t+1} = (1+g)m_{t}$，在实际货币余额恒定的稳态下，物价水平的增长率必须等于货币增速，即通货膨胀率 $\pi = \frac{P_{t+1}}{P_{t}} - 1 = g$，故 $\frac{P_{t+1}}{P_{t}} = 1+g$。

我们将利用一阶条件求解 $c$ 和 $l$：
首先，将 $c_{t+1}$ 的一阶条件代入 $m_{t+1}$ 的一阶条件中：
$$\lambda_{t+1} + \mu_{t+1} = \frac{1}{P_{t+1}c_{t+1}} \implies \lambda_{t} = \frac{\beta}{P_{t+1}c_{t+1}}$$
结合 $l_{t}$ 的一阶条件 $\lambda_{t} = \frac{1}{P_{t}(1-l_{t})}$，可得：
$$\frac{1}{P_{t}(1-l_{t})} = \frac{\beta}{P_{t+1}c_{t+1}}$$
代入稳态条件 $c_{t+1} = c$，$l_{t} = l$ 以及 $\frac{P_{t+1}}{P_{t}} = 1+g$，得到边际替代率与相对价格的关系：
$$\frac{1}{1-l} = \frac{\beta}{(1+g)c} \implies c = \frac{\beta(1-l)}{1+g} \quad \text{（等式 1）}$$

其次，根据商品市场出清条件（可行性约束），当期生产等于当期消费：
$$c = A + l \quad \text{（等式 2）}$$

联立等式 1 和等式 2：
$$A + l = \frac{\beta(1-l)}{1+g}$$
$$(A+l)(1+g) = \beta - \beta l$$
$$A(1+g) + l(1+g) + \beta l = \beta$$
$$l(1+g+\beta) = \beta - A(1+g)$$

由此解得稳态劳动供给 $l$ 为：
$$l = \frac{\beta - A(1+g)}{1+g+\beta}$$

将其代入等式 2，解得稳态消费 $c$ 为：
$$c = A + \frac{\beta - A(1+g)}{1+g+\beta} = \frac{A(1+g+\beta) + \beta - A(1+g)}{1+g+\beta} = \frac{\beta(A+1)}{1+g+\beta}$$

**综上所述，稳态时的竞争性均衡结果为：**
* 消费量：$c = \dfrac{\beta(A+1)}{1+g+\beta}$
* 劳动供给量：$l = \dfrac{\beta - A(1+g)}{1+g+\beta}$
* 储蓄量：$s_{t+1} = 0$

### 4) 对于政府制定的不同的货币增速 $g$ 都有一个对应的稳态竞争性均衡 。请求出一个最优的 $g^{*}$，和对应的名义利率 $R^{*}$，使得与此 $g^{*}$ ($R^{*}$) 对应的稳态竞争性均衡下的消费者一生效用达到最大（10 分） 。

我们需要寻找一个使得稳态竞争性均衡下消费者一生效用最大化的 $g^{*}$。稳态单期效用函数为 $U(c, l) = \ln(c) + \ln(1-l)$。

首先计算闲暇 $1-l$：
$$1-l = 1 - \frac{\beta - A(1+g)}{1+g+\beta} = \frac{1+g+\beta - \beta + A(1+g)}{1+g+\beta} = \frac{(1+g)(1+A)}{1+g+\beta}$$

将 $c$ 和 $1-l$ 代入效用函数，定义稳态福利函数 $W(g)$：
$$W(g) = \ln\left( \frac{\beta(A+1)}{1+g+\beta} \right) + \ln\left( \frac{(1+g)(1+A)}{1+g+\beta} \right)$$
利用对数性质展开：
$$W(g) = \ln(\beta) + 2\ln(1+A) + \ln(1+g) - 2\ln(1+g+\beta)$$

对 $g$ 求一阶导数以寻找极值点：
$$\frac{dW(g)}{dg} = \frac{1}{1+g} - \frac{2}{1+g+\beta} = \frac{1+g+\beta - 2(1+g)}{(1+g)(1+g+\beta)} = \frac{\beta - (1+g)}{(1+g)(1+g+\beta)}$$

令 $\frac{dW(g)}{dg} = 0$，解得最优货币增速 $g^{*}$：
$$\beta - (1+g^{*}) = 0 \implies g^{*} = \beta - 1$$

接下来求解对应的最优名义利率 $R^{*}$。根据储蓄的一阶条件：
$$\lambda_{t} = \beta \lambda_{t+1}(1+R) \implies 1+R = \frac{\lambda_{t}}{\beta \lambda_{t+1}}$$
由于 $\lambda_{t} = \frac{1}{P_{t}(1-l)}$，在稳态下实际闲暇 $1-l$ 为常数，拉格朗日乘子 $\lambda_{t}$ 的衰减率完全由物价增长率决定，即 $\frac{\lambda_{t}}{\lambda_{t+1}} = \frac{P_{t+1}}{P_{t}} = 1+g$。代入上述等式得：
$$1+R = \frac{1+g}{\beta}$$

将求得的最优货币增速 $g^{*} = \beta - 1$ 代入：
$$1+R^{*} = \frac{1 + (\beta - 1)}{\beta} = \frac{\beta}{\beta} = 1 \implies R^{*} = 0$$

**结论与意义：**
使得消费者一生效用达到最大的最优货币增速为 $g^{*} = \beta - 1$，对应的名义利率为 $R^{*} = 0$。这在宏观经济学中被称为**弗里德曼法则 (Friedman Rule)**。该法则指出，最优的货币政策应当消除持有货币的机会成本，使名义利率降为零，从而完全消除货币先行约束对家庭消费与劳动供给决策所造成的扭曲。

## 【作业 1.3 收益率曲线】

假设代表性家庭存在 3 期，其生命周期的效用函数是：

$$U=\ln C_{t}+\beta\ln C_{t+1}+\beta^{2}\ln C_{t+2}$$

现在允许家庭之间跨期借贷，即债券市场上存在跨期的债券产品，使得家庭在第 t 期就能为第 t+2 期的消费进行储蓄，实现跨期借贷 。则代表性家庭每一时期的预算约束如下所示：

$$Y_{t}=C_{t}+S_{t,1}+S_{t,2}$$

$$Y_{t+1}+(1+r_{t,1})S_{t,1}=C_{t+1}+S_{t+1,1}$$

$$Y_{t+2}+(1+r_{t+1,1})S_{t+1,1}+(1+r_{t,2})S_{t,2}=C_{t+2}+S_{t+2,0}$$

其中 $r_{t,1}$ 是 t 到 t+1 时期之间的储蓄利率（对应在债券市场上是 t 时期购买、到期期限为 1 期的即期债券收益率），$r_{t+1,1}$ 是 t+1 到 t+2 时期的储蓄利率（对应在债券市场上是 t+1 时期购买、到期期限为 1 期的远期债券收益率），$r_{t,2}$ 是 t 到 t+2 时期的储蓄利率（对应在债券市场上是 t 时期购买、到期期限为 2 期的远期债券收益率），特别地我们有：

$$1+r_{t,2}=(1+r_{t,1})(1+r_{t+1,1})$$

### 1) 对最终时期储蓄的条件是什么？换句话说，$S_{t+2,0}$ 应该等于多少，为什么？ 

对于三期模型，最终期（即第 $t+2$ 期）期末的储蓄必须满足：

$$S_{t+2,0} = 0$$

这一设定源于理性的代表性家庭最大化其生命周期的总效用。一方面，家庭在生命终结后无法继续消费，留下正的财富不能带来任何额外效用（满足「横截性条件」或无庞氏骗局条件）；另一方面，家庭也不被允许在生命周期结束时留下未偿还的债务。因此，最优的决策是恰好消耗掉所有的收入和之前积累的财富。
### 2) 使用这一最终条件，将上述三期预算约束转换为整个生命周期的预算约束（一生的预算约束） 。并利用两期模型生命周期的预算约束来解释这一预算约束的直观含义 。

>$Hint$：代换消掉 $S_{t,1}, S_{t,2}, S_{t+1,1}$，并证明代表性家庭一生的预算约束如下所示（允许家庭之间跨期借贷）：
>$$C_{t}+\frac{C_{t+1}}{1+r_{t,1}}+\frac{C_{t+2}}{(1+r_{t,1})(1+r_{t+1,1})}=Y_{t}+\frac{Y_{t+1}}{(1+r_{t,1})}+\frac{Y_{t+2}}{(1+r_{t,2})}$$

已知三期的预算约束如下：

(1) $Y_{t} = C_{t} + S_{t,1} + S_{t,2}$

(2) $Y_{t+1} + (1+r_{t,1})S_{t,1} = C_{t+1} + S_{t+1,1}$

(3) $Y_{t+2} + (1+r_{t+1,1})S_{t+1,1} + (1+r_{t,2})S_{t,2} = C_{t+2} + S_{t+2,0}$

将 $S_{t+2,0} = 0$ 代入式 (3) 中，整理得到 $S_{t+1,1}$ 的表达式：

$$S_{t+1,1} = \frac{C_{t+2} - Y_{t+2} - (1+r_{t,2})S_{t,2}}{1+r_{t+1,1}}$$

由式 (1) 可得 $S_{t,1} = Y_{t} - C_{t} - S_{t,2}$，将其代入式 (2) 中：

$$Y_{t+1} + (1+r_{t,1})(Y_{t} - C_{t} - S_{t,2}) = C_{t+1} + S_{t+1,1}$$

将前面得到的 $S_{t+1,1}$ 代入此式：

$$Y_{t+1} + (1+r_{t,1})(Y_{t} - C_{t}) - (1+r_{t,1})S_{t,2} = C_{t+1} + \frac{C_{t+2} - Y_{t+2} - (1+r_{t,2})S_{t,2}}{1+r_{t+1,1}}$$

等式两边同时乘以 $(1+r_{t+1,1})$：

$$(1+r_{t+1,1})Y_{t+1} + (1+r_{t,1})(1+r_{t+1,1})(Y_{t} - C_{t}) - (1+r_{t,1})(1+r_{t+1,1})S_{t,2} = (1+r_{t+1,1})C_{t+1} + C_{t+2} - Y_{t+2} - (1+r_{t,2})S_{t,2}$$

根据无套利条件 $1+r_{t,2} = (1+r_{t,1})(1+r_{t+1,1})$，上式左右两边关于 $S_{t,2}$ 的项恰好完全抵消，得到：

$$(1+r_{t+1,1})Y_{t+1} + (1+r_{t,2})(Y_{t} - C_{t}) = (1+r_{t+1,1})C_{t+1} + C_{t+2} - Y_{t+2}$$

两边同时除以 $(1+r_{t,2})$，并利用等价关系 $\frac{1+r_{t+1,1}}{1+r_{t,2}} = \frac{1}{1+r_{t,1}}$，得出：

$$\frac{Y_{t+1}}{1+r_{t,1}} + Y_{t} - C_{t} = \frac{C_{t+1}}{1+r_{t,1}} + \frac{C_{t+2}}{1+r_{t,2}} - \frac{Y_{t+2}}{1+r_{t,2}}$$

移项整理后，证明了代表性家庭一生的预算约束如下：

$$C_{t} + \frac{C_{t+1}}{1+r_{t,1}} + \frac{C_{t+2}}{(1+r_{t,1})(1+r_{t+1,1})} = Y_{t} + \frac{Y_{t+1}}{1+r_{t,1}} + \frac{Y_{t+2}}{1+r_{t,2}}$$

**直观含义解释：** 这一公式与两期模型生命周期的预算约束在直觉上是等价的，即家庭在生命周期内的总消费现值（Present Value）必须等于其一生禀赋总收入的现值。跨期借贷的引入使得家庭可以完全打破当期流动性的束缚，仅基于一生的总财富跨期平滑其消费轨迹。

## 3) 求解上述三期消费-储蓄问题，找到代表性消费者的最优解需满足的条件（5 分） 。

>$Hint$：从（2）中得到的生命周期的预算约束中得到 $C_{t}, C_{t+1}$ 和 $C_{t+2}$ 的关系，并将问题转化为没有约束的优化问题 。推导两个欧拉方程，一个涉及 $C_{t}$ 和 $C_{t+1}$，另一个则涉及 $C_{t+1}$ 和 $C_{t+2}$ 。

利用拉格朗日乘数法求解约束优化问题。构造拉格朗日函数 $\mathcal{L}$ 如下：

$$\mathcal{L} = \ln C_{t} + \beta\ln C_{t+1} + \beta^{2}\ln C_{t+2} + \lambda \left[ Y_{t} + \frac{Y_{t+1}}{1+r_{t,1}} + \frac{Y_{t+2}}{1+r_{t,2}} - C_{t} - \frac{C_{t+1}}{1+r_{t,1}} - \frac{C_{t+2}}{1+r_{t,2}} \right]$$

分别对 $C_{t}$、$C_{t+1}$ 和 $C_{t+2}$ 求一阶偏导数，并令其等于零：

$$\frac{\partial \mathcal{L}}{\partial C_{t}} = \frac{1}{C_{t}} - \lambda = 0 \implies \lambda = \frac{1}{C_{t}}$$

$$\frac{\partial \mathcal{L}}{\partial C_{t+1}} = \frac{\beta}{C_{t+1}} - \frac{\lambda}{1+r_{t,1}} = 0 \implies \lambda = \frac{\beta(1+r_{t,1})}{C_{t+1}}$$

$$\frac{\partial \mathcal{L}}{\partial C_{t+2}} = \frac{\beta^{2}}{C_{t+2}} - \frac{\lambda}{1+r_{t,2}} = 0 \implies \lambda = \frac{\beta^{2}(1+r_{t,2})}{C_{t+2}}$$

通过联立消去乘子 $\lambda$，我们可以得到两个欧拉方程（Euler Equations）。

联立第一式与第二式，得到关于 $C_{t}$ 和 $C_{t+1}$ 的欧拉方程：

$$\frac{C_{t+1}}{C_{t}} = \beta(1+r_{t,1})$$

联立第二式与第三式，得到关于 $C_{t+1}$ 和 $C_{t+2}$ 的欧拉方程：

$$\frac{C_{t+2}}{C_{t+1}} = \beta \frac{1+r_{t,2}}{1+r_{t,1}} = \beta(1+r_{t+1,1})$$
### 4) 市场均衡时，我们有 $C_{t}=Y_{t}, C_{t+1}=Y_{t+1}$ 以及 $C_{t+2}=Y_{t+2}$ 。请写出 $r_{t,1}, r_{t+1,1}$ 以及 $r_{t,2}$ 关于外生收入 $Y_{t}, Y_{t+1}, Y_{t+2}$ 以及 $\beta$ 的表达式 。 

在市场均衡且没有跨期实物存储技术的条件下，每一期的商品市场必须出清，即所有产出在当期被消费：$C_{t} = Y_{t}$，$C_{t+1} = Y_{t+1}$，$C_{t+2} = Y_{t+2}$。

将均衡条件代入前面的欧拉方程中：

对于 $t$ 到 $t+1$ 期的即期利率 $r_{t,1}$：

$$1+r_{t,1} = \frac{Y_{t+1}}{\beta Y_{t}} \implies r_{t,1} = \frac{Y_{t+1}}{\beta Y_{t}} - 1$$

对于 $t+1$ 到 $t+2$ 期的远期利率 $r_{t+1,1}$：

$$1+r_{t+1,1} = \frac{Y_{t+2}}{\beta Y_{t+1}} \implies r_{t+1,1} = \frac{Y_{t+2}}{\beta Y_{t+1}} - 1$$

对于 $t$ 到 $t+2$ 期的长期利率 $r_{t,2}$，利用公式 $1+r_{t,2} = (1+r_{t,1})(1+r_{t+1,1})$：

$$1+r_{t,2} = \left( \frac{Y_{t+1}}{\beta Y_{t}} \right) \left( \frac{Y_{t+2}}{\beta Y_{t+1}} \right) = \frac{Y_{t+2}}{\beta^{2} Y_{t}} \implies r_{t,2} = \frac{Y_{t+2}}{\beta^{2} Y_{t}} - 1$$

### 5) 债券的收益率曲线 (The Yield Curve) 是显示一组货币和信贷风险均相同，但期限不同的债券收益率的图表 。纵轴代表收益率，横轴则是距离到期的时间 。收益率曲线的形状，是根据连上在直轴不同债券收益率点以及在横轴的债券年期点而成，可能有向上倾斜、水平以及向下倾斜三种趋势 。对应在我们的例子中，若 $r_{t,2}>r_{t,1}$，则表示债券的收益率曲线向上倾斜；$r_{t,2}<r_{t,1}$，则表示债券的收益率曲线向下倾斜；$r_{t,2}=r_{t,1}$，则表示债券的收益率曲线水平 。

#### a) 若 $Y_{t}=Y_{t+1}=Y_{t+2}$，则表示债券的收益率的呈什么趋势（收益率曲线的斜率是正还是负）？

#### b) 「倒置的收益率曲线」通常可作为判断经济衰退的先行指标，若 $Y_{t+2}\ll Y_{t+1}, Y_{t+2}\ll Y_{t}$，即第 t+2 期产出远小于第 t 期及第 t+1 期，现在收益率曲线的斜率呈什么趋势（收益率曲线的斜率是正还是负）？出现了反转吗？

**a) 产出持平的情况：$Y_{t} = Y_{t+1} = Y_{t+2} = Y$**

将相同产出代入均衡利率的表达式中可得：

$$1+r_{t,1} = \frac{1}{\beta}$$

$$1+r_{t,2} = \frac{1}{\beta^{2}}$$

由于主观贴现因子通常满足 $0 < \beta < 1$，故有 $\beta^{2} < \beta$。这推导出 $\frac{1}{\beta^{2}} > \frac{1}{\beta}$，即 $r_{t,2} > r_{t,1}$。

**结论：** 此时收益率曲线**向上倾斜**（正斜率）。从微观逻辑上看，由于家庭对于未来的消费更缺乏耐心，若要诱导他们在更长的期限内持有债券并推迟消费，长期债券必须提供比短期债券更高的溢价回报。

**b) 经济衰退的情况：$Y_{t+2} \ll Y_{t+1}$ 且 $Y_{t+2} \ll Y_{t}$**

我们需要比较 $1+r_{t,2}$ 与 $1+r_{t,1}$ 的比值：

$$\frac{1+r_{t,2}}{1+r_{t,1}} = \frac{\dfrac{Y_{t+2}}{\beta^{2} Y_{t}}}{\dfrac{Y_{t+1}}{\beta Y_{t}}} = \frac{1}{\beta} \frac{Y_{t+2}}{Y_{t+1}}$$

由于 $Y_{t+2}$ 远小于 $Y_{t+1}$，使得比值 $\frac{Y_{t+2}}{Y_{t+1}}$ 极小。只要经济衰退的幅度足够深，以至于满足 $\frac{Y_{t+2}}{Y_{t+1}} < \beta$，就会导致 $\frac{1+r_{t,2}}{1+r_{t,1}} < 1$，即 $r_{t,2} < r_{t,1}$。

**结论：** 此时收益率曲线的斜率为负，呈现**向下倾斜**的趋势，即**出现了反转**（Inverted Yield Curve）。当理性的代表性家庭预见到远期（$t+2$ 期）收入将遭遇断崖式下跌时，为了实现消费平滑，他们会激增对长期无风险债券的需求。这种防范性的储蓄行为大幅推高了长期债券的价格，从而在均衡状态下压低了长期债券的收益率。
